Entry for the [make.fun bounty "The Meeting That Should Have Been an Email"](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9): one joke line, at most 200 characters, about a meeting that should have been an email.

## Entry

> The meeting ended with a decision to send an email summarizing the meeting about the email.

## How it works

`main.py` writes the line to `/output/entry.txt`, enforcing the gate: UTF-8 text, 1–200 characters, a single non-blank line, no control characters, verified by a read-back round-trip.

Run it with:

```sh
python3 main.py
```
